# Mara — Arreglos de Costura v2.0

Versión enfocada exclusivamente en Mara y sus arreglos de costura en Oberá, Misiones.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Publicar en Vercel

1. Subir el proyecto al repositorio de GitHub.
2. Vercel detecta Vite automáticamente.
3. Build command: `npm run build`
4. Output directory: `dist`

## Datos centrales

Para cambiar teléfono, servicios, imágenes o dirección:

`src/lib/site.ts`
